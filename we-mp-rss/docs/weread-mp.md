# 微信读书公众号采集

当公众号后台接口不可用时，可以把采集模式切换为微信读书 Web。该模式直接请求 `weread.qq.com`，不经过第三方中转，并继续使用现有的 `MP_WXS_*` Feed ID 和 RSS 地址。

## 配置

1. 登录 `https://weread.qq.com`，打开任意公众号页面。
2. 在浏览器开发者工具的 Network 面板找到微信读书的正常请求。
3. 从 Request Headers 复制完整 `Cookie`。有效登录不代表公众号接口一定放行；遇到 `-2041` 时参见下方安全验证说明。
4. 在管理页的“微信读书公众号采集”中保存，或设置环境变量：

```env
GATHER.MODEL=weread_mp
WEREAD_COOKIE=wr_vid=...; wr_skey=...; wr_rt=...
WEREAD_CONTENT_INTERVAL=2
```

需要在 RSS 中直接显示全文时，同时设置：

```env
GATHER.CONTENT=True
```

## 行为

- 主路径使用 `GET /web/mp/articles?bookId=&offset=` 翻页读取文章列表，按已入库记录增量采集。旧文档据部分失败响应判断接口废弃，此判断已撤回。
- 正文来自 `GET /web/mp/content?reviewId=`，提取正文 HTML 或页面提供的正文文本；JSON 业务错误保留业务码及简短脱敏说明。
- 明确的 `-2012` 登录过期可用原账号续期凭据请求一次正常续期，成功后仅重试原请求一次；通过原请求验证后才保存新凭据。同一采集器不反复续期，不覆盖用户更新过的登录。其他认证、验证、访问限制及 JSON 业务错误停止，不换账号或绕过限制。`-2041`、`-2012`、HTTP 499 本身不足以证明日配额耗尽或确定恢复时间。
- 其他列表接口错误在尚未成功读取列表时，保留 `/api/mp/cover` 最新一篇的兜底；不能用其绕过认证或访问限制。
- 列表主路径中正文失败的文章不入库，整次任务不会更新同步时间。历史 cover 兜底仍可能保存空正文，不应将其视为全文交付成功。
- 连接测试只验证书架接口。扫码及书架测试成功不代表公众号列表、全文接口均可访问。

## 划线 / 笔记采集（weread 模式）

- `GATHER.MODEL=weread` 时采集**书架电子书**的划线/笔记（`/web/book/bookmarklist`）。
- 公众号订阅书（`MP_WXS_*`）在微信读书内没有划线数据，划线模式下会自动跳过并提示。
- 手动「采集」接口（`/weread/collect`）会自动分档：指定 `MP_WXS_*` bookId 时走公众号文章采集，普通电子书走划线采集。

## 限制

- 列表返回范围受微信读书接口及本地页数、日期筛选配置限制；cover 兜底只能读取最新一篇，不能回补完整历史。
- 凭据失效、访问限制和接口异常需按原始错误及正常网页状态分别核对，不能仅凭 `-2012`/`-2041` 要求重复扫码。通过环境变量提供的凭据优先于管理页保存值。
- 请求间隔能控制本地频率，不保证消除服务端限制。遇到认证、验证或访问限制时停止请求，按微信读书正常页面处理。

## `-2041` 安全验证与恢复边界

- 微信读书[官方网页代码](https://cdn.weread.qq.com/web/wrwebnjlogic/js/app.d51b45eb.js)在收到 `-2041`（`-0x7f9`）时调用腾讯验证码，用户完成后携带 `x-wr-ticket`、`x-wr-randstr` 重新提交原请求。这说明官方客户端如何处理该错误，不揭示平台判定账号、网络或请求频率的具体规则。
- 腾讯[票据校验文档](https://cloud.tencent.com/document/api/1110/36926)说明普通验证票据有效期为五分钟，并会检查重复使用。因此不能把一次验证的票据当作长期 API Key 保存，也不能把重新扫码登录当作完成了安全验证。
- 当前采集器在验证拒绝后保留已有文章，停止本轮采集；定时任务使用同一采集登录，因此也停止后续客户的来源请求。同步记录保留错误码和出错接口，区分列表与正文失败。下次用户主动同步或原有日程仍可正常发起任务，不增加自动重试、换号或备用接口绕过。
- 当前没有云端人工验证恢复界面。可验证的恢复方向是：由本人在发生问题的会话和网络环境中使用微信读书官方页面完成它要求的验证，再确认原失败请求成功。仅在手机或另一台电脑上正常阅读，不能证明云端已经恢复。云端正常人工验证能否打通仍需实测，不承诺补一个弹窗就能解决。
- 腾讯[官方 Agent API](https://github.com/Tencent/WeChatReading/blob/main/skills/search.md)支持搜索公众号和文章，但公开文档没有给出与本工作台等价的“按公众号增量获取全部新文章及全文”能力。不能把搜索结果当作完整订阅流，或据此宣布更换 API Key 就能解决采集问题。

截至 2026-11-11，离线回归能验证停止范围、保留数据和错误定位；不证明后续真实采集不再触发验证，也没有固定冷却时长的依据。

微信读书请求头与扫码登录使用同一固定浏览器标识，避免通用采集基类的随机设备标识；这项修正不构成服务器错误码根因的证明。

2026-11-10 修正：续期成功必须由本次响应下发凭据且无业务错误，不能仅在请求的 Cookie jar 中看到旧值就宣告成功；扫码保存会合并完整验证后的登录与续期凭据，文件保存成功后才向页面报告登录成功。38项相关离线检查通过，实际连续运行寿命仍需观察。
