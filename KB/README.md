# 客户知识与内容工作台（本地融合版）

以原知识库项目为主系统，接入公众号监测与 Eason 检索。资料管理、知识整理、研究策划、内容写作、内容检查、人工审核、引用与草稿版本继续保留。来源基线为 `2f99d1dd7d26c1a5efa5303c65d6d1c48a4016d5`；原历史保留在来源仓库，见根目录 SOURCE_VERSIONS.md。

本目录是 [eason-workbench 单仓库](../README.md) 的知识库主系统，配套采集器在 [../we-mp-rss](../we-mp-rss/)。一次克隆即包含两部分代码；启动、停止和备份脚本位于仓库根目录。运行数据库、登录凭据、API 密钥与备份不放 GitHub。

## 本地运行

当前 Windows 已安装 Node 24.14、pnpm 11.25 和采集器 Python 3.12.13 环境。先按根目录说明准备采集器和管理员账号，然后在本目录执行：

```sh
pnpm install --frozen-lockfile
node scripts/configure-local.mjs
pnpm build
```

按 [根目录安装说明](../README.md) 准备环境后，双击 `启动本地版.cmd`，浏览器打开 `http://127.0.0.1:5173/`。启动器同时管理采集器、知识库和后台任务三个本地服务。结束时使用 `停止本地版.cmd`。具体路径、账号、备份与恢复见 [运行说明](../LOCAL_RUN.md) 和 [验收记录](../VERIFICATION.md)。

交付入口运行构建后的 Worker，使用本地 D1/R2。启动器将 `.dev.vars` 复制到 `dist/server/.dev.vars` 供 Wrangler 读取，并限制 Windows 文件权限；该私密生成文件不进入 Git 或静态资产。源码更新后应停机、备份、重新 `pnpm build`，再用启动器启动。

单独 `pnpm dev` 是开发服务器，不作为交付入口；`pnpm start` 只启动已准备配置副本的知识库，未包含采集器和后台调度。本分支采用真实本地账号登录，统一登录未配置时 API 拒绝访问。默认仅环回地址监听，未部署公网。

## 客户与内容权限

- 每个账号可创建最多两个未归档客户空间，创建者可管理、归档和恢复自己的空间。管理员创建登录账号、分配协作成员和内容、维护模型与采集授权。
- 普通账号可以自建知识库，无需等待分配；其他账号的空间仍需明确授权。内部成员共享被授权客户的资料、知识和任务，外部成员只读明确分享的内容。
- “允许对外引用”控制知识写作资格，不能让外部账号自动阅读原件。
- 列表、详情、下载、历史、检索、模型上下文均在服务端核对客户范围。修改使用修订冲突保护。
- 空间可归档和恢复，原件、审核结果与历史不删除。归档暂停后续自动步骤；进行中的请求可能已产生服务商费用。
- 公开源码不包含私人预置资料。全新安装资料库为空，用户可上传自己的资料；已有数据库中的资料不受影响。

## 使用路径

上传资料 → 查重与解析 → 成功后保存原件和解析结果 → 知识整理 Agent → 人工选取并保存待确认知识 → 原文审核与引用权限 → 正式知识库。

监测来源 → 近期/累计文章 → Eason 检索标题、主题词和正文 → 选择参考文章用于策划 → 研究策划 Agent 提出选题 → 人工选题 → 确认正式 Sources → 研究大纲 → 人工确认 → 写作 → 检查 → 人工确认 → Markdown 导出。

Eason / 检索页默认在右侧展开助手，可收起为窄栏；收起保留当前输入与对话，窄屏改为右侧抽屉。

知识库直接创建 Brief 的原路径保留，不要求经过监测。监测文章仅作选题参考，不能自动变成已确认的客户事实。

## 文件、版本与容量

支持 Markdown、PDF、DOCX、PPTX、XLSX、UTF-8 TXT。原文件20 MiB以内、Markdown和转换结果2 MiB以内；PDF最多100页文本层，不含OCR；第一期不支持视频。

同客户按原件和解析内容指纹去重；同名不同内容保留新版本。内存临时解析失败不会留下永久原件。新上传租约持久化，同客户并发上传会得到409，请稍后重试；已保存文件不受影响。异常停机的上传租约最多等待10分钟后清理其未完成对象。

每客户上传资料默认512 MiB，80%提醒，到限拒绝新增；统计原件与解析对象，不是整台电脑或全部数据库容量。监测数据库、草稿快照和普通日志需要随实际数据增长关注。不会自动删除有效业务资产。

来源新版审核确认后旧版退出可用知识检索；原文与历史引用快照保留。知识可编辑、拆分、合并、确认或撤回；高风险内容仍需逐条核对。

## 后台与模型

四类 Agent 保留独立指令和证据边界。后台每5秒检查持久队列，同时最多执行两项知识库任务；Eason另有最多两项对话并行及有界排队。关页面不会停止已启用自动流程；Sources、主题、大纲、知识保存和终审仍等待人工操作。失败不自动付费重试，用户明确重试后继续已保存阶段。中断运行状态最多约3分钟后显示失败，不能保证供应商对失败请求不收费。

四类知识与内容 Agent 的管理员共享模型设置支持官方 OpenAI/DeepSeek 固定 HTTPS 地址、连接测试、失败保留旧配置、停用回退和修订冲突。密钥使用 AES-256-GCM 服务端加密，读取接口不返回密钥。Eason 使用采集连接区域中的独立 DeepSeek 模型配置，两处不联动。当前复用已有 API，不宣称模型自研或自训。兼容 JSON Object 时仍进行服务端严格结构与逐字引文验证。管理员连接、环境回退与加密主密钥位置见 [LOCAL_RUN.md](../LOCAL_RUN.md)。

Sources最多60条候选、人工选1–20条事实；适用写作规则独立应用。生成与编辑保存草稿及来源快照。历史可查看和下载，未加入一键恢复编辑、自由Flow、向量数据库或自动发布。

## 验证

```sh
pnpm test
node tests/fusion-access.integration.mjs
node tests/fusion-uploads.integration.mjs
node tests/fusion-pages.integration.mjs
pnpm build
node scripts/check-local-access.mjs
```

上述集成使用隔离数据库和模型替身。访问边界检查需要本地服务已启动，不调模型。`node scripts/accept-local-fusion.mjs` 是历史联合验收工具，会创建虚构样本、账号并产生真实模型费用，不作为全新安装或公开版本验收步骤；`--self-test` 可离线运行。

当前公开版本的检查范围见 [VERIFICATION.md](../VERIFICATION.md)。未在 Mac 或新的云服务器上实测。腾讯接口拒绝时保留失败事实与已取得文章，不把缓存或模拟结果当成当前采集成功。
